# 空间塔（维度模式）

对应 #35。原 `changede:space_tower` 改名为空间塔（桥接模式），保留注册 ID、制作配方和转换行为，不申请区块加载。新 `changede:dimension_space_tower` 复用同一材质。单格合成支持桥接模式空间塔与维度模式空间塔双向转换，无额外材料。

## 使用

1. 在两端各放置一个维度模式空间塔，右键打开界面。
2. 设置同一公共频道（1–9999）和同一能源类型（LP / WLP / DLP）。0 或清空频道表示退出。
3. 供电端选择“输入 → 频道”；用电端选择“频道 → 输出”。
4. 两端启用空间锚定，按需要配置红石控制，并连接对应能源的管道或机器。

每台塔保留三份独立的 50,000 单位本地缓存，切换能源类型不丢失缓存，也不转换能源。每塔输入、输出及频道传输分别限制为每服务器 tick 100 单位。频道在服务器范围内共享，可以连接相同或不同维度的多个端点；轮换优先级，避免固定端点长期独占传输。没有中央能源池，区块加载与能源传输分别管理。

## 空间锚定

Jade 提示分别显示 LP、WLP、DLP 三行实际缓存，与当前选择的传输类型无关。空缓存显示 0；不会把 LP 当成 DLP，也不会共用进度条导致文字重叠。服务器验证包含截图中的 50000/0/0 和三种不同缓存值。

选定有效频道、打开开关、传输模式非停用且红石允许运行的塔，为自己申请 Forge **fully ticking** block-owner ticket。无需另一端已有能量或在线，避免两端等待对方造成恢复死锁。

工作范围是塔的 X/Z 坐标各扩展一格形成的最小区块矩形：中央 1 个、贴边 2 个、角落 4 个目标区块（含负坐标）。覆盖塔及六面相邻设备；不会固定申请 3×3 个 ticket。Forge 可能为加载目标区块而加载外围依赖区块，因此界面数量指本塔持有的目标 ticket 数，非维度实际加载区块总数。

桥接模式、未配频道、未启用或被红石停用的塔不持有 ticket。清空频道、停用、拆除或替换方块时释放自身 ticket；相同区块的其他塔不受影响。区块/世界卸载与拆除分开处理，服务器关闭保留有效 ticket。Forge 重启校验会加载并核对保存的 owner，移除无效 owner、旧范围和非 ticking ticket，随后有效塔恢复注册。

红石停用后，如果本区块真的卸载，塔无法感知后续信号；需要玩家或其他加载器让该区块再次运行。界面提供这一提示。

持续运行保证覆盖这个工作范围内正常执行 block/entity tick 的设备。长管线、远处机器或更大工厂还需其他加载器；作物等随机刻机制仍服从游戏规则。断电、缺料、管道配置错误也不会由加载器自动解决。

## 验证

`verifyDimensionTower` 检查区块边界及负坐标、跨维度地址、频道/能源隔离、限流、能量守恒、多节点公平分配、停用和重注册清理。

`runDimensionTowerServer` 使用 `build/dimension-tower-server` 内的隔离测试世界，需沿用已接受 EULA 的开发服务器配置。第一次运行验证 19 个 CE 科技方块、研究台、Changed 的 Infuser/Purifier 和 Addon 的普通/高级 Unifuser/Catalyzer 的真实生存挖掘掉落、库存释放及电量保留，验证 LP/WLP/DLP 跨维度传输、ticket 释放及无人胶空间内跨边界电炉在 600 tick 后继续炼铁，并保存重启样本与实际产量；第二次用 `-PdimensionTowerRestart=true` 验证自动恢复 ticket、产量增长和拆除后释放。观察窗口留出区块启动时间，产量必须增长至少 4 个。测试仅在对应 JVM 属性启用时运行，正常游戏不触发。

## 拆除时保留电量

Changed 的 `ChangedBlock` 与净化器直接返回物品、不经过掉落表，通过 Mixin 在该返回处使用与全局掉落修饰器相同的能源保留逻辑。

机器掉落由 Forge 全局掉落修饰器补充 `BlockEntityTag`，重放通过原版放置流程恢复能源。仅复制已知数值储能字段，覆盖 CE 的 LP/WLP/DLP、本地管道、桥接空间塔焦耳余量与 CE 缓存，以及 Changed/Addon 经 CE 接入的工作台能源。影响范围限定到这三个模组的能源处理器，并仅修改本机的一个原有掉落物。

库存、液体、研究进度、坐标、区块 ticket 和网络注册状态不会被复制；库存仍正常单独掉落，避免重复物品。零电量机器沿用普通掉落。CE 缓存容量依赖 RPM/SU，因此这两个容量参数与其储能一起保留。基础 LP 储能的 NBT 加载改为赋值而非追加，防止重载增加电量。

手动验收：两端分别在主世界和胶空间；把远端塔放在区块角落，六面设备跨边界；离开胶空间且无人在线超过 300 tick，确认机器仍工作。保存并重启后确认持续工作；测试频道 0、开关、停用模式、红石暂停和拆除释放 ticket；同区块放置两塔后拆除一个，另一个的加载应保留。桥接模式不应新增 Forge ticket。
